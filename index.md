# OpenCode Labs

These labs use [OpenCode](https://opencode.ai/) as a case study of a coding agent. Start by using it to
explore and improve a website; later labs will examine how the features work.

[Lab 1: Getting Started with OpenCode]({{ '/lessons/getting-started/' | relative_url }})

Install OpenCode, connect a model, and work through a website project on your computer.
