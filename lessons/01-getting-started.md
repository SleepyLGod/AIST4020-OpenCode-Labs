# Lab 1: Getting Started with OpenCode

In previous labs, you built small examples of model calls, tool calling, and
agent loops. Now we will use **[OpenCode](https://opencode.ai/)**, an open-source coding agent that brings
these pieces together to work on a project.

We will install OpenCode and ask it to improve a toy website, without editing
the application code ourselves. Later labs will examine its **harness** and how
these features are implemented.

Work through these three sections:

1. [Set Up OpenCode]({{ '/lessons/getting-started/install/' | relative_url }})
2. [Explore the Website]({{ '/lessons/getting-started/explore/' | relative_url }})
3. [Improve the Website]({{ '/lessons/getting-started/build/' | relative_url }})
